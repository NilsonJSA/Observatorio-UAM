# AstroUAM 🔭

**Sistema de agendamiento multiplataforma con asistente inteligente para el Observatorio Copérnico.**

Proyecto de culminación de estudios de **Ingeniería en Sistemas** de la Universidad Americana (UAM).

## Descripción

AstroUAM permite la **programación y validación automatizada de observaciones astronómicas**, incorporando un asistente inteligente para apoyar el proceso de agendamiento.
